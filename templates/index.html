Security Advice & Policies

  • Rule 1: Always rotate keys once exposed in shared repositories or chats.
  • Rule 2: Store credentials in `.env` and load them via environment variables.
  • Rule 3: Redacting a copy creates a safe distribution, but doesn't revoke leaked keys.
  • Rule 4: Use our pre-commit hook to catch secrets before staging.

Safe Team Developer Handoff

Configure projects collaboratively without pasting real API keys into team chats or public repositories.

1. Environment Template (.env.example)

Template containing variable names and placeholder assignments only. Zero real secret values.

2. Local Encrypted Vault (Owner-Controlled)

Safely store and label local environment keys on your machine. Values are encrypted with authenticated Scrypt + AES-256-GCM. Admins cannot view private secrets.

LeakLens IDE Guard & Git Pre-Commit Hook

Detect and prevent leaks right inside your developer workflow.

VS Code Extension

Get in-editor highlighting, line/column diagnostics, and automated QuickFix recommendations to move secret literals into environment variables.

  1. Ensure LeakLens is running: python app.py
  2. Open ide-extension/ in VS Code.
  3. Run npm install && npm run compile
  4. Press F5 to test or package the extension.
Backend Endpoint: http://127.0.0.1:5000/api/ide/scan
Operates in-memory with zero disk persistence.

Git Pre-Commit Hook

Block accidental commits containing high or medium risk credentials automatically.

Run the install command in your terminal:

python scripts/install-hook.py

Tests staged files using git diff --cached before allowing commits.
