02 // Multi-Layer Inspection

One inspection. Multiple layers of detection.

LeakLens combines deterministic patterns, surrounding code context, and local ML-assisted classification so findings are both fast and explainable.

LAYER 01 // DETERMINISTIC RULES

Pattern & structural matching

Detects known token prefixes, key formats, private key headers, and structured PII patterns with predictable rule definitions.

LAYER 02 // CONTEXT CHECKS

Surrounding signal analysis

Evaluates variable names, comments, file paths, and entropy to separate likely live credentials from harmless test fixtures.

LAYER 03 // LOCAL ML-ASSISTED

Probabilistic classification

Scores ambiguous strings and unstructured text locally to surface potential exposure that rigid regex rules alone may miss.

Note: Detection combines heuristic and statistical layers; no automated scanner guarantees 100% recall.

06 // Architecture & Boundaries

Security should not create another privacy problem.

Local-First Boundary Files stay within your configured execution boundary — processing location is determined by your deployment configuration.
Encrypted credential vault Two-factor authentication Feedback reporting Verification rescans
  • LeakLens supports local-first processing, with where files are processed determined by your deployment configuration.
  • Findings pair detection with provider-specific blast-radius context so teams can prioritize real risk.
  • No automated scanner catches every possible leak; always review findings before sharing sensitive files.
  • Redaction cleans your output copy — it does not revoke a credential that was already exposed, so rotate affected secrets with their provider.
