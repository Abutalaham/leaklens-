GOOD TO KNOW

Questions,
answered.

Clear answers about how LeakLens handles your files.

Are my files sent to a cloud API?

LeakLens is designed for local-first scanning. Review your deployment and configuration to understand any network behavior in your own environment.

Does redaction revoke a leaked credential?

No. Redaction creates a safer copy; rotate any real credential that may already have been exposed.

Which files can I inspect?

Supported extensions and upload limits are shown in the scanner and are loaded from the running application.

Can I prevent secrets from reaching a commit?

Use IDE Guard and the Git pre-commit hook to inspect your workflow before changes are committed.

    Security Best Practices

    Never share real API keys or credentials. Commit .env.example files containing placeholders only. Keep actual credentials in your account-scoped vault or secure environment configuration.

    How the vault works

    New vault entries use per-entry Scrypt-derived keys and AES-256-GCM authenticated encryption before server-side storage. The server application can decrypt entries for password-protected portable exports; this is not a client-side or zero-knowledge vault. Portable exports use a separate password-derived Scrypt key and AES-256-GCM, and importing re-encrypts entries for the signed-in account.

    The vault listing returns variable names, categories, and masked previews only. Secret values are not returned by the listing endpoint.

    LeakLens IDE Guard & Git Pre-Commit Hook

    Detect and prevent leaks right inside your developer workflow.

    VS Code Extension

    Get in-editor highlighting, line/column diagnostics, and automated QuickFix recommendations to move secret literals into environment variables.

    1. Ensure LeakLens is running: python app.py
    2. Open ide-extension/ in VS Code.
    3. Run npm install && npm run compile
    4. Press F5 to test or package the extension.
    Backend Endpoint: http://127.0.0.1:5000/api/ide/scan
    Operates in-memory with zero disk persistence.

    Git Pre-Commit Hook

    Block accidental commits containing high or medium risk credentials automatically.

    Run the install command in your terminal:

    python scripts/install-hook.py

    Tests staged files using git diff --cached before allowing commits.
